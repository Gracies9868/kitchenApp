# 冰箱魔法师 (Fridge Wizard)

## 项目简介
冰箱魔法师是一款面向上班族的轻量化 Android 应用，旨在帮助用户利用现有食材快速生成美味菜谱。通过输入食材或目标菜品，结合智能推荐技术，为用户提供健康、美味、简单的烹饪灵感。

## 功能特点
1. **食材输入与识别**：支持手动输入或拍照识别食材。
2. **菜谱推荐**：根据食材或菜品需求生成健康菜谱，支持时间、口味等筛选条件。
3. **菜谱详情**：提供烹饪步骤、食材清单及营养信息。

## 技术栈
- **语言**：Java
- **开发工具**：Android Studio

## 安装与运行
1. 克隆代码仓库：
   ```bash
   git clone https://github.com/Gracies9868/kitchenApp.git
   ```
2. 在 Android Studio 中打开项目并运行。
